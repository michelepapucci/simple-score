SIMPLE

A reference-free metric for sentence simplification that also says how sure it is. Give it a sentence and a simplification of it; no reference simplification needed.

Reading the score

SIMPLE returns a score μ between −1 and +1 for each (source, simplification) pair:

−1 unrelated or degenerate text0 copy of the source+1 successful simplification

Negative scores flag unsuccessful simplifications, including complexifications. Each score comes with σ, the model's own uncertainty: most predictions sit near the minimum of 0.05; a larger σ means the model is less sure, and the example deserves a human look.

Try it in your browser

The demo runs SIMPLE-small entirely on your device: nothing you type is sent anywhere. Starting it downloads the model once (≈ 180 MB); your browser keeps it, so later visits start quickly.

This demo uses SIMPLE-small with 8-bit weights; its scores are within about ±0.015 of the full model's. For evaluations, use the Python package below (SIMPLE-large by default).

Use it in Python

pip install simple-metric
from simple_metric import SIMPLE

metric = SIMPLE.from_pretrained("large")      # or "small", "base"
out = metric.score(sources, simplifications)
out.mu, out.sigma, out.mean

With 🤗 Evaluate:

import evaluate

simple = evaluate.load("mpapucci/simple", "large")
simple.compute(sources=sources, predictions=simplifications)

Models: small, base, large. Code and training: github.com/michelepapucci/simple-metric. Paper: Rethinking Text Simplification Evaluation as Preference Learning (link coming soon).
